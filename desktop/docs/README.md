# Marker Desktop Wiki

PDF·이미지를 LLM이 읽기 쉬운 Markdown·HTML·JSON·구조별 chunks로 변환하는 오프라인 데스크톱 앱입니다. 한국어/영어 화면을 지원합니다. 파일과 인식 모델은 PC 안에서 처리됩니다. 별도 Python/.NET 설치, 계정, API 키가 필요하지 않습니다.

## 설치와 시작

- Windows x64: `MarkerDesktop-0.1.0-win-x64.msi`를 실행합니다. 현재 사용자 계정의 프로그램 폴더에 설치됩니다. 시작 메뉴 또는 바탕화면의 **Marker Desktop Offline**을 실행하세요. 제거는 Windows 설정의 설치된 앱에서 합니다.
- Linux x64: `chmod +x MarkerDesktop-0.1.0-linux-x64.run` 후 `./MarkerDesktop-0.1.0-linux-x64.run`을 실행합니다. 사용자 홈 아래에 설치하고 애플리케이션 메뉴를 등록합니다. Linux용 패키지는 Windows용 Python이나 DLL을 사용하지 않습니다.
- 설치와 최초 실행 중 인터넷 다운로드는 하지 않습니다. 모델이 빠진 설치본은 변환을 시작하지 않고 오류를 표시합니다.
- CPU 기본 버전입니다. RAM 16GB 이상과 모델·출력용 충분한 디스크 공간을 권장합니다. 대형 스캔 PDF는 시간이 오래 걸립니다. 진행 막대는 완료 파일 수이며 정확한 페이지별 진행률이 아닙니다.

## 문서 변환

1. **파일 추가**에서 PDF 또는 이미지를 선택합니다. 여러 파일은 순서대로 처리합니다.
2. **저장 위치**를 지정하고 출력 형식을 고릅니다.
3. 처음에는 빠른 모드, 체크박스 모두 해제로 시작합니다.
4. **문서 변환**을 누릅니다. **취소**는 실행 중인 작업과 하위 인식 프로세스를 종료합니다.
5. **결과 폴더 열기**로 저장된 결과를 확인합니다. 기존 파일을 덮어쓰지 않도록 입력마다 별도 폴더를 만듭니다.

입력: PDF, PNG, JPEG, TIFF, BMP, WebP. 이 배포판은 DOCX/PPTX/XLSX/EPUB/HTML 입력을 제공하지 않습니다. 출력 HTML과 입력 HTML은 다릅니다.

## 출력 형식과 이미지

- Markdown: 제목·문단·표·수식과 이미지 링크. 이미지 파일을 같은 결과 폴더에 저장합니다. `.md`만 복사하면 이미지가 빠집니다. 폴더 전체를 이동하세요.
- HTML: 문서 구조와 이미지 링크. 함께 저장한 이미지 파일이 필요합니다.
- JSON: 중첩된 문서 구조, 위치·타입 정보와 인코딩된 이미지.
- Chunks: 평탄화한 문서 블록. `page`는 0부터 시작하는 실제 페이지 번호이며 위치·제목 계층 정보를 포함합니다. 고정 토큰 길이 분할, 임베딩과 벡터 DB 저장은 별도 작업입니다.

텍스트 전용 LLM은 Markdown 이미지 링크만으로 그림을 해석하지 않습니다. 그림 해석에는 이미지 입력을 지원하는 모델 또는 별도의 설명이 필요합니다. OCR 결과는 원문 언어를 유지하며 문서를 번역하지 않습니다.

## 설정

- **언어**: 우측 상단에서 한국어/English를 즉시 전환합니다. 다음 실행에도 유지됩니다.
- **빠르게**: 가벼운 레이아웃 인식과 PDF 텍스트 추출을 사용하고 필요한 부분만 OCR합니다.
- **정밀하게**: OCR/VLM 기반 레이아웃을 더 많이 사용합니다. CPU에서 더 느릴 수 있습니다. 항상 정확도가 높아지는 것은 아닙니다.
- **페이지 범위**: 비우면 전체, `0,2-5`는 첫 페이지와 3~6번째 페이지입니다. 목록의 모든 문서에 적용됩니다.
- **모든 페이지를 OCR로 다시 읽기**: 포함된 텍스트가 잘못된 경우 사용합니다. 정상 글자도 달라질 수 있습니다.
- **OCR 건너뛰기**: PDF 텍스트만 추출합니다. 스캔 글자와 이미지 수식은 빠질 수 있습니다. 강제 OCR/기존 OCR 무시와 동시에 선택할 수 없습니다.
- **기존 OCR 텍스트 무시**: 숨겨진 OCR 텍스트 레이어가 있는 페이지를 다시 읽습니다.
- **머리말·꼬리말 유지**: 반복 문서명·페이지 번호 등을 결과에 남깁니다.
- **진단 파일 저장**: 중간 이미지와 인식 영역을 결과 폴더에 보존합니다. 정확도를 올리는 옵션은 아닙니다.
- 외부 LLM 보정은 이 버전에 없습니다. 로컬 OCR/VLM은 포함되어 있으며 API 키가 필요하지 않습니다.

## 문제 해결

- 글자가 누락됨: OCR 건너뛰기를 해제합니다. PDF 텍스트가 깨지면 강제 OCR을 시도하세요.
- 일부 파일 실패: 작업 내역에 파일별 오류가 표시되고 다음 파일은 계속 처리합니다.
- 모델 누락: 전체 설치본을 다시 설치하세요. 실행 중 모델을 다운로드하지 않습니다.
- 원본과 결과의 문구·표·수식을 대조하세요. OCR/변환 결과의 정확도는 보장되지 않습니다.
- 로그 폴더 열기: 요청 경로, 엔진 오류와 모델 서버 로그를 실행별로 저장합니다. 원본 경로나 문서 내용이 포함될 수 있으므로 로그도 내부 자료로 취급하세요.
- 앱 설정/로그: Windows `%LOCALAPPDATA%\MarkerDesktop`, Linux의 .NET LocalApplicationData 아래 `MarkerDesktop`. 결과 문서는 사용자가 고른 폴더에 남습니다. 제거해도 결과를 삭제하지 않습니다.
