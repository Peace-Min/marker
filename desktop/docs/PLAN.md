# Marker Desktop: 기획 · 개발 · QA · Wiki

상태: 기획·개발·QA·로컬 Wiki 완료. 2026-10-23 생성한 최종 Windows/Linux 설치본과 설치 후 변환 결과를 2026-10-26 재확인했다. 최종 설치 파일/검증 기록은 artifacts/release에 있다.

## 제품 범위

폐쇄망 PC에 설치하면 별도 Python/.NET 설치나 모델 다운로드 없이 PDF·이미지를 Markdown, HTML, JSON, 구조별 chunks로 변환한다. Avalonia 화면은 Windows/Linux 공통이며 한국어와 영어를 실행 중 전환한다. 외부 LLM 호출은 제공하지 않는다. CPU 실행을 기본으로 한다.

## 사용자 흐름

파일 추가 → 출력 폴더 선택 → 형식·OCR 설정 → 순차 변환 → 결과 폴더 열기. 상태, 취소, 파일별 오류, 로그를 제공한다. 성공한 결과를 덮어쓰지 않고 실행별 폴더에 보존한다. 앱 종료 시 자신이 실행한 엔진과 하위 프로세스를 정리한다.

## 구현

- Avalonia/C# 화면과 로컬 Python 작업 프로세스. JSON Lines로 상태·결과 통신.
- OS별 Python, CPU PyTorch, Marker/Surya, llama.cpp, 모델, 폰트, 라이선스를 함께 배포.
- 모델 경로 고정, 외부 네트워크 연결 거부, Hugging Face 오프라인 모드. 사용자 홈의 모델 캐시에 의존하지 않음.
- Windows는 사용자별 설치/제거 EXE. Linux는 독립 실행 번들과 사용자별 설치 스크립트.
- 언어별 리소스, 설정 저장, 고급 옵션 설명. OCR 강제/비활성 동시 선택 방지.

## QA 통과 조건

1. UI 빌드, 한국어/영어 키 일치와 언어 전환, 옵션 상호 배제.
2. 새 경로·빈 캐시·외부 통신 거부 상태에서 일반 PDF, 스캔 이미지, 이미지 포함 문서 변환. 출력 이미지 링크 확인.
3. 공백/한글 경로, 잘못된 입력, 중복 이름, 취소 후 프로세스 정리, JSON/HTML/chunks 출력.
4. 배포물의 모든 파일 해시와 모델 존재 검사. 설치본을 새 경로에 설치한 뒤 번들 엔진 검증.
5. Linux는 실제 실행 증거가 있을 때만 검증 완료로 기록. 크로스 빌드만으로 실행 성공을 주장하지 않음.
