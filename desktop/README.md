# Marker Desktop Offline

Avalonia/.NET 10 desktop front end for the existing Marker Python engine. Korean/English UI, CPU inference, bundled models/runtime, PDF and image input, Markdown/HTML/JSON/chunks output. Windows and Linux use separate packages. No external LLM API or runtime downloads.
